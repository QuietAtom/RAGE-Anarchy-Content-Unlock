# RAGE-Anarchy-Content-Unlock
A simple text file edit for RAGE that unlocks the otherwise unavailable Anarchy content.



Rage Anarchy Content Unlock


What is this mod?
A simple text file edit for RAGE that unlocks the otherwise unavailable Anarchy content.
You will start with the Anarchy pistol and fists immediately, but to unlock the Anarchy armour, you need to progress to the point in the game where you can purchase the armour from Coffer in Wellsprings (located opposite the bounty board).
For the Anarchy vehicle, you only need to progress far enough to unlock the garage in Wellsprings, which happens around the same point in the story.

Installation
MUST HAVE RAGE SEWERS DLC INSTALLED!

Manually download the file, extract its contents, and copy them into your game's main installation directory (where RAGE is installed).
Example:

C:\Program Files (x86)\Steam\steamapps\common\RAGE


Compatibility
No known conflicts. If you encounter any issues, please let me know.

How to Uninstall
Remove the dlc1 subfolder located inside the dlc folder in your game's main installation directory.
